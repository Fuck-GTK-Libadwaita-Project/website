操你妈的 GNOME 基金会

一封写给 GNOME 基金会与生态维护者的反讽公开信

我们曾经相信，桌面 Linux 的意义在于自由：自由地使用、自由地修改、自由地让自己的电脑长得像自己的电脑。

但这些年，GNOME 基金会和它周围的生态一次又一次提醒我们：所谓「自由」，好像只包括按他们规定的方式使用电脑的自由。


Flathub 限制 LLM 辅助应用上架。一个本应中立的应用分发平台，开始替所有用户预先做出价值判断。你想装什么，不再由你决定，而由委员会决定。

libadwaita 以「设计一致性」压倒用户偏好。生态开发者用一套私有样式层锁死主题能力，发行版和用户的美化需求被定义为「不被支持的使用方式」。（是的，我们就是在说 StopTheming。）

GTK 几乎变成 GNOME 的私有产物。名义上是自由软件工具包，实际上路线、API 和发布节奏完全围绕 GNOME Shell 的需求运转，其他基于 GTK 的桌面环境和应用沦为二等公民。

维护者权力过度集中。重大争议中的透明度和程序正义不足：社区讨论常常在结论已定之后才发生，「社区」更多时候是被通知，而不是被咨询。

过快、过于激进的 API 演进。破坏性变更一个版本接一个版本地到来，下游开发者的迁移成本被轻描淡写为「进步的代价」。

兼容性负担被下放给扩展维护者和用户。每次 Shell 和 API 变动之后，收拾残局的永远是不拿工资的扩展作者，以及升级之后发现桌面坏掉的普通用户。


我们并不反对设计一致性，也不反对进步。我们反对的是：把「一致性」当成不可质疑的教条，把「进步」当成破坏兼容性的免罪金牌，把用户的电脑当成基金会的设计实验场。

电脑是我们的，不是你们的。请把选择权还给用户。
